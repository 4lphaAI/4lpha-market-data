# bStock sector labels — handoff to the execution plane (2026-09-26)

Additive. No existing field changed; a consumer that ignores `sectors` sees the same payload as before.

## What is new

- Every row in the **bStocks** lane of `GET /universe` now carries `sectors: string[]`. Ondo rows carry no `sectors` field.
- `GET /universe?lane=bstocks&sector=<label>` returns only the bStocks with that label. `?sector=` without `lane` does the same. `sector` with any other lane → 400 `invalid_sector`. An unknown label → 400.
- `meta.lanes.bstocks.sectors = { fixedGeneratedAt, trendingAsOf, trendingStaleness }`.

## How to read it

- **Labels are the data plane's names, not Binance's.** The API filters by `tabId` but returns no tab names; each name was inferred from the tickers in the tab.
- **Fixed labels are a frozen file**, regenerated by hand. They do not update themselves.
- **`trending` is read once a day at 14:00 UTC.** Treat it as a UI hint, not a trade signal. Check `trendingStaleness`: after 72 h the label disappears from every row rather than going stale in place.
